# 理论推导审稿清单

Theory / Review Agent 在输出结论前须自检。

## 符号与格式

- [ ] 符号与 `symbols.md` 一致
- [ ] 假设与 `assumptions.md` 编号对应
- [ ] 公式使用完整 `$$...$$` 块（复杂表达式）
- [ ] 无 Unicode 数学符号，一律 LaTeX

## 逻辑严谨性

- [ ] 区分 **已证明** / **待证** / **启发式猜测**
- [ ] 禁止无依据的「显然」「易得」「不难看出」
- [ ] 每步等式变换标注依据（代数 / 引理 X / 文献 / 自证）
- [ ] 维度与矩阵形状一致

## 验证

- [ ] 可符号化的结论已调用 SymPy 或标注待验证
- [ ] 不可符号化时已标注数值验证（Experiment Agent）
- [ ] 边界条件与反例已讨论

## 引用

- [ ] 文献引用来自检索结果或 arXiv ID，不编造
- [ ] 自证结论标注「自证」
