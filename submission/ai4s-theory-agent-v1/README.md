## 第 3 项：演示视频

| 文件 | 说明 |
|------|------|
| `demo/AI4S-智能体演示-3min.mp4` | 1280×720，约 **2 分 34 秒**（≤3 分钟） |

成片为「字幕讲解版」。复现成片：

```bash
/path/to/.venv/bin/python demo/build_demo_video.py
```

（需本机提供中文字体；脚本会按常见路径查找。）

## 本地运行系统（便于对照演示）

```bash
cd <仓库根>
.venv/bin/uvicorn server.main:app --host 0.0.0.0 --port 8000 --app-dir app
# 浏览器打开 http://127.0.0.1:8000
```

需配置 `conf/.env` 中的 `DEEPSEEK_API_KEY` 等（密钥勿提交进本材料包）。
